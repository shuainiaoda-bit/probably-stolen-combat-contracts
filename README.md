## 安装与版本

适配游戏版本：**0.46D / 1.0.0.14 / 1.0.0.15**。语言：全部 11 种官方语言。

退出游戏，将压缩包内 `CombatContracts` 文件夹放入游戏目录的 `Mods` 文件夹，在游戏原生 Mod 菜单启用。

首次使用及更新前请备份存档。同一个 Mod 只启用一个来源。停用前请先查看包内说明并妥善处理模组物品与进度。 停用前先返店结束战斗并处理板甲打印；保留模组物品和存档进度。

## English

By 是大帅鸟. Version 0.4.13 for Probably Stolen.

Contracts, faction bounties, turn-based combat, equipment, progression and shop defense.

Supported game version: **0.46D / 1.0.0.14 / 1.0.0.15**. Languages: All 11 official game languages.

Exit the game, copy the `CombatContracts` folder into the game's `Mods` directory and enable it through the native Mod menu.

Back up your saves before installation and updates. Enable one copy of each mod. Read the included instructions before disabling a mod that owns saved items or progress. Return to the shop, finish combat and resolve armor printing before disabling Combat Contracts.

Download `CombatContracts-0.4.13.zip` from the release Assets. `SHA256SUMS.txt` contains its SHA-256 checksum. GitHub's automatic Source code archives contain repository documentation.
